# 애플리케이션 현황 진단

운영 중인 앱이 Terroir 로 들어올 수 있는지, 들어온다면 **BYOR 과 greenfield 중 어느 경로인지** 가리는 것이 목적이다.
그 판단의 근거인 기술 스택·아키텍처·앱 구조·도커라이징·배포 파이프라인을 중심으로 **정해진 목차의 아티팩트 한 개**를 만든다.
이관을 돕는 사람은 그 링크 하나로 경로를 정하고 첫 미팅 안건을 잡는다.

원본은 이 스킬 디렉토리의 두 파일이다. 이 문서에 내용을 옮겨 적지 않는다 — 두 곳에 두면 한쪽만 고쳐져 두 경로의 결과가 달라진다.

| 파일 | 정하는 것 |
|---|---|
| `references/format.md` | 무엇을 조사하는가 — 목차 · 작성 규칙 · 결과 만드는 순서 |
| `references/report-template.html` | 어떻게 보이는가 — 디자인이 고정된 리포트 틀. JSON 칸만 바꾼다 |

**경로는 1차 의견까지만 낸다.** 「BYOR」 · 「greenfield」 · 「확인 필요」 중 하나와 근거를 적는다.
최종 결정과 사내 표준의 세부 대조는 결과를 받은 쪽이 한다.

## 1. 직접 실행할지 전달할지 묻는다

사용자의 말에 이미 답이 있으면 묻지 않는다. 없으면 AskUserQuestion 으로 묻는다.

| 선택지 | 뜻 |
|---|---|
| 직접 진단 | 이 세션에서 앱의 소스 코드를 읽어 아티팩트를 만든다 → 3절 |
| 담당자에게 전달 | 앱 담당자가 자기 Claude 에서 돌릴 프롬프트를 출력한다. 담당자에게 이 플러그인이 없어도 된다 → 2절 |

같은 질문에 **앱 이름**도 함께 묻는다. 모르면 비워 둔다.

## 2. 전달 — 프롬프트를 출력한다

1. `references/format.md` 를 읽는다.
2. `<앱 이름>` 을 1절에서 받은 값으로 바꾼다. 받지 못했으면 자리표시를 그대로 둔다 — 받는 사람이 채운다.
3. 파일 전체를 **코드 블록 하나**로 출력한다. 문장을 고치거나 줄이지 않는다.
4. 코드 블록 위에 전하는 법을 짧게 붙인다.
   - 담당자는 앱의 소스 코드가 있는 폴더에서 Claude Code 를 열고 이 블록을 그대로 붙여 넣는다
   - Claude Code 가 없으면 claude.ai 에 소스 파일을 올리고 붙여 넣어도 된다. 다만 읽을 수 있는 파일이 적어 「알 수 없음」 이 늘어난다
   - 결과 아티팩트 링크를 요청한 사람에게 보내 달라고 함께 전한다

여기서 끝낸다. 아티팩트를 만들지 않는다.

## 3. 직접 — 진단할 대상을 받는다

로컬 경로나 원격 저장소 주소를 받는다. 현재 디렉토리가 앱 저장소로 보이면 그것을 첫 선택지로 제시한다.

| 받은 것 | 하는 일 |
|---|---|
| 로컬 경로 | 그 경로를 읽는다. `git status` 로 커밋하지 않은 변경도 본다 |
| 원격 주소 | 세션 임시 디렉토리에 `git clone --depth 1` 로 받아 읽는다. 받지 못하면 권한 문제일 수 있다고 알리고 로컬 경로를 다시 묻는다 |

원격 주소로 받으면 커밋하지 않은 변경과 로컬 `.env` 는 볼 수 없다. 해당 항목은 「알 수 없음」 으로 쓰고 이유를 적는다.

## 4. 진단해서 아티팩트로 만든다

1. `references/format.md` 를 읽고 「지킬 것」 과 목차 순서대로 조사한다.
   - 소스 코드를 고치지 않는다. 클라우드 조회는 읽기 명령만 쓴다
   - 비밀값이 든 파일은 키 이름만 본다. 값을 결과에 옮기지 않는다
   - Dockerfile 이 없어도 새로 만들지 않는다. 만들 수 있는지만 판단한다
   - 사전 체크의 실행 계정명·조직 소속·플러그인은 이 세션을 실행한 사람 기준이다. 확인할 수 있는 명령이 있으면 읽기로만 확인한다
   - 사용자 수·접속 환경처럼 코드에 없는 것은 사용자에게 한 번에 묶어서 묻는다. 모르면 「알 수 없음」 으로 둔다
2. 「결과 형식」 대로 리포트를 만든다. 틀은 공개 주소가 아니라 이 스킬의 `references/report-template.html` 을 읽는다.
   - 틀을 작업 디렉토리로 복사하고, JSON 칸과 `<title>` 의 앱 이름만 바꾼다
   - JSON 문자열에 닫는 태그 모양이 들어가면 빗금 앞에 역빗금을 넣는다
3. 세션에 아티팩트 도구가 있으면 그 HTML 을 게시하고 **링크를 준다.** 없으면 맨 앞에 `<!doctype html>` 을 붙여 `<앱 이름>-현황진단.html` 로 저장하고 경로를 준다.
4. 마지막 응답에는 링크, 이관 경로 1차 의견과 근거 한 줄, 「알 수 없음」 항목 수와 누구에게 물으면 되는지를 짧게 적는다.
