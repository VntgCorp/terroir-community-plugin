# infosec

플랫폼정보보호팀이 만든 보안 점검 스킬 모음입니다. 지금은 `vsecu-review` 하나가 들어 있습니다.

## 설치

```
/plugin install infosec --marketplace VntgCorp/terroir-community-plugin
```

**이미 zip 으로 설치하신 분은 먼저 지우셔야 합니다.** 같은 이름의 스킬이 PC 에 따로 있으면
`/vsecu-review` 는 그 사본을 실행합니다. 제거 방법은 사내 안내 페이지에 있습니다.

## 무엇을 하는가

이미 돌아가는 웹서버 코드를 **사내 보안 기준에 비추어 점검하고, 요청하면 그 자리에서 고칩니다.**

AI 가 만든 코드는 보안 사항이 빠진 채로 나오는 일이 잦습니다. 그렇다고 무엇을 봐야 하는지
매번 적어가며 점검할 수는 없어서, 이름 하나만 붙이면 기준 전체로 점검되게 만들었습니다.

기준 표준은 KISA 「소프트웨어 보안약점 진단가이드(2021)」 입니다. 구현단계 보안약점 49개
항목 전부와 대응 관계를 유지하고, 사내 기준으로 따로 둔 항목을 더해 운용합니다. 사내 정보보호
규정(개발보안·암호화 지침)에서 정한 사항이 코드에 실제로 반영되도록 돕습니다.

**결과는 이렇게 나옵니다.**

| 판정 | 뜻 |
|---|---|
| 위반 | 문제가 있습니다. `파일:줄` 과 수정 방법이 함께 나옵니다 |
| 준수 | 확인했고 올바릅니다 |
| 해당 없음 | 그 항목이 걸릴 코드가 없습니다 (근거가 붙습니다) |
| 확인 불가 | 코드만으로 판단할 수 없습니다. 질문에 답해주셔야 합니다 |

위반에는 위험도가 붙습니다. **상**은 고쳐야 통과, **중**은 정보보호팀과 상의, **하**는 통과입니다.

점검이 끝나면 작업 폴더에 `보안점검-결과-날짜-시각.txt` 가 쌓입니다. 등급별 건수와 종합 판정,
나온 위반이 한 줄씩 들어 있습니다. **코드도 파일 경로도 프로젝트 이름도 담기지 않습니다.**

## 쓰는 법

```
/vsecu-review 해당 웹서버 점검해줘        점검만 합니다. 코드는 건드리지 않습니다
/vsecu-review --fix 나온 취약점 조치해줘   점검 결과를 낸 뒤 이어서 고칩니다
```

정식 이름은 `/infosec:vsecu-review` 입니다. 이름이 겹치지 않으면 `/vsecu-review` 로 부릅니다.

**부를 때만 동작합니다.** 붙이지 않으면 평소의 Claude Code 그대로입니다.

점검 중에 코드만으로 알 수 없는 것이 남으면 **질문이 옵니다. 답해주세요.**
모르면 답하지 않아도 됩니다 — 그 항목은 「확인 불가」로 남고, 무엇을 정해줘야 하는지 리포트에
적힙니다. 추측으로 판정하지 않습니다.

`--fix` 는 고치기 전에 원본을 백업합니다. 프로젝트 최상위에 `보안점검-수정전-날짜-시각`
폴더가 생기고, 원래 경로 구조 그대로 들어갑니다. **확인이 끝나면 지우세요. 배포물에 넣으면 안 됩니다.**

## 전제 조건

| | |
|---|---|
| 외부 도구 | 없음 |
| 접근 권한 | 없음. 네트워크 연결도 필요하지 않습니다 |
| 다른 플러그인 | 없음 |

운영체제(Windows · macOS · Linux)와 언어(Java · Python · JavaScript · Go · C# …)를 가리지
않습니다. git 저장소가 아니어도, 로컬 폴더만 있어도 동작합니다.

## 알려진 한계

- **오탐과 미탐이 모두 있습니다.** 「위반 없음」이 「안전함」을 뜻하지 않습니다.
- **한 번으로 다 잡히지 않습니다.** 실측에서 서로 다른 두 번의 점검이 각각 다른 결함을
  찾았습니다. 인증·인가·결제·개인정보를 건드리는 변경은 새 세션에서 한 번 더 점검하세요.
- **고친 뒤에는 새 세션에서 재점검하세요.** 수정 자체가 새 결함을 만들 수 있고, 같은 세션에서
  이어 점검하면 방금 고친 것을 통과시키는 쪽으로 기웁니다.
- **수백 개 파일을 한 번에 넣지 마세요.** 리포트가 길어져 읽히지 않습니다. 나눠서 돌립니다.
- **`--fix` 는 「상」만 고칩니다.** 중·하는 손대지 않습니다 — 중은 상의 대상이고, 하는 통과
  등급이라 운영 코드를 건드릴 이유가 없습니다.
- Claude Code 전용입니다. 클로드 웹에서 쓰는 방법은 사내 안내 페이지에 따로 있습니다.
