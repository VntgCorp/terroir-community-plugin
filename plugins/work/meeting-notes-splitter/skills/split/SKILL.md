# 회의록을 결정 사항과 할 일로 분리하기

사용자가 붙여넣은 회의록 **텍스트**를 읽고, 그 안에서

- **결정된 것** — 회의에서 합의·확정된 내용
- **해야 할 일** — 앞으로 누군가 처리해야 하는 작업

을 뽑아 두 절로 나눠 정리한다.

## 전제

- 입력은 **이미 텍스트로 옮겨진 회의록**이다. 음성 녹취 원문(오디오 파일, STT 로그 등)을
  입력으로 받았다면 이 스킬의 대상이 아니라고 알리고, 먼저 텍스트로 옮겨 달라고 안내한다.
- 회의록에 화자 표시나 시간순 흐름이 없어도 동작해야 한다 — 메모 형태로 두서없이
  적힌 텍스트도 들어올 수 있다.

## 절차

1. **회의록 전문을 받는다.** 사용자가 아직 붙여넣지 않았다면 요청한다.
2. **결정 사항을 추출한다.** 다음에 해당하면 결정으로 본다.
   - 회의 중 합의·확정되었다고 명시된 내용 ("하기로 했다", "확정", "결정")
   - 여러 안 중 하나를 선택했다고 분명히 적힌 내용
   - 단순히 논의되었을 뿐 결론이 나지 않은 내용은 **포함하지 않는다** — 애매하면
     결정이 아니라 할 일(또는 미결 사항)로 분류한다.
3. **할 일을 추출한다.** 다음에 해당하면 할 일로 본다.
   - 누군가 앞으로 해야 한다고 명시된 작업 ("~하기로", "~할 것", "확인 필요", "액션 아이템")
   - 담당자나 기한이 텍스트에 적혀 있으면 함께 적는다. **적혀 있지 않은 담당자·기한을
     추측해서 채우지 않는다** — 비워 두거나 "미지정"이라고 적는다.
4. **두 절로 정리해 보여준다.**

   ```markdown
   ## 결정된 것
   - <결정 내용>

   ## 해야 할 일
   - <할 일> (담당: <담당자 또는 미지정>, 기한: <기한 또는 미지정>)
   ```

5. 회의록 중 어느 쪽에도 속하지 않는 일반 논의 내용은 분류에 넣지 않는다. 두 절에
   넣을 것이 없으면 "없음"이라고 적는다 — 억지로 채우지 않는다.

## 하지 않는 것

- 녹취 원문(오디오)을 텍스트로 옮기는 일은 하지 않는다.
- 회의록에 없는 내용을 추론해서 보태지 않는다 — 문서에 적힌 것만 가지고 분류한다.
