# meeting-notes-splitter

회의 직후 받아적은 회의록 텍스트를 결정된 것과 해야 할 일로 나눠 정리한다.

## 무엇을 하는가

회의록 텍스트를 붙여넣으면 그 안에서 **결정된 것**(합의·확정된 내용)과 **해야 할 일**
(앞으로 처리해야 하는 작업)을 뽑아 두 절로 나눠 보여준다. 담당자·기한이 텍스트에 적혀
있으면 같이 적고, 없으면 추측하지 않고 미지정으로 둔다.

## 쓰는 법

회의록 전문을 붙여넣고 "결정된 거랑 할 일 나눠서 정리해줘" 처럼 요청하면 뜬다.
직접 부르려면:

```
/meeting-notes-splitter:split
```

## 아는 한계

- **음성 녹취 원문(오디오, STT 로그)은 다루지 않는다.** 이미 텍스트로 옮겨진 회의록만
  입력으로 받는다.
- 회의록에 결정·할 일이 명확히 적혀 있지 않으면(애매하게 논의만 된 내용) 분류
  정확도가 떨어진다 — 모호하면 할 일 쪽으로 보수적으로 분류한다.
- 담당자·기한이 텍스트에 없으면 추측해서 채우지 않는다. 비어 있는 채로 나온다.
- 회의 내용의 사실 여부(실제로 그렇게 결정됐는지)를 검증하지 않는다 — 입력된 텍스트를
  그대로 믿고 분류만 한다.
