# Changelog

## 1.1.0 - 2026-11-26

### 추가
- 페이지 맨 위에 한 문장 결론 · 숫자 셋 · 「2주를 어디에 썼나」 막대 · 회고 세 칸을 더해 근거 자료를 읽기 전에 이번 스프린트가 어땠는지 알 수 있게 했습니다.
- 이슈 트래커의 스프린트 소속과 팀 경계가 어긋난 티켓이나 계획 뒤 취소된 티켓을 어느 스프린트 · 묶음에 셀지 정하는 규칙을 더했습니다.
- 송년회처럼 「한가함」으로 표시된 종일 행사나 30분 이하 간격으로 붙은 회의도 일할 수 있는 날에서 정해진 기준으로 빼는 규칙을 더했습니다.

### 변경
- 작업 시간을 기록하지 않는 팀에서 1분 안에 여러 티켓의 상태를 한꺼번에 옮긴 것은 활동으로 세지 않도록 바꿨습니다.
- 다음 스프린트 티켓을 쌓는 순서를 기한 · 우선순위 · 진행 중 여부 · 만든 순서로 정해 실행할 때마다 순서가 달라지지 않게 바꿨습니다.
- 스킬 문서와 README 의 문장을 읽기 쉽게 다듬었습니다.

### 수정
- 회의 화면에 페이지를 띄웠을 때 본문 폭이 좁고 설명 글자가 작고 흐려 읽히지 않던 문제를 고쳤습니다.
- 「대표 작업 전후」 섹션을 빼면 「지난 계획과 비교」까지 함께 사라지던 문제를 고쳤습니다.
